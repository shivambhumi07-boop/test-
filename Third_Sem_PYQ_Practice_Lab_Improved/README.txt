# 3rd Sem PYQ Practice Lab

Open `index.html` in a browser. For best compatibility, serve this folder with a simple local web server (for example VS Code Live Server or `python -m http.server`).

Features:
- Subject → Mid/End/Other → Year → Paper selectors
- One-question-at-a-time practice flow
- Original source PDF page shown beside each question
- Upload answer as image / text / PDF
- Optional image OCR using Tesseract.js when internet is available
- Local rubric-based automatic marks
- Weak-topic dashboard and attempt history stored in browser localStorage

Important: the automatic marks are a heuristic estimate. They do not replace teacher grading and do not reliably verify derivations, diagrams, calculations, or handwriting. The supplied PDFs that are image-only are shown as exact source pages rather than having invented question text.

Papers included: 39
